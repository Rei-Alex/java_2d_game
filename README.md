# GAMEVER — Visual Algorithm Puzzle Game
Двухмерная логическая игра-головоломка с элементами визуального программирования, написанная на чистой **Java (SE)** с использованием библиотеки **Swing / AWT**.
## О проекте
В **GAMEVER** игрок управляет агентами («Героями») на клеточном поле. Задача на каждом уровне — составить последовательность команд и условных инструкций, чтобы провести героев к целевым клеткам, перемещая блоки и избегая препятствий (ям).
### Основные возможности
* **Визуальный конструктор алгоритмов:** добавление, вставка и удаление инструкций (`Вверх`, `Вниз`, `Влево`, `Вправо`, `Поднять`, `Положить`).
* **Условные операторы (`if`):** проверка окружения агента по 9 направлениям с операторами `==` и `!=` на наличие объектов (`Герой`, `Блок`, `Яма`) и поддержкой блоков кода `{ ... }`.
* **Плавная пошаговая анимация:** визуализация выполнения каждой команды на многослойном поле (`JLayeredPane`) с помощью `javax.swing.Timer`.
* **Настраиваемый интерфейс:** переключение экранов через `CardLayout` и выбор цветовой темы оформления (тёмно-серый, синий, светло-серый).
## Архитектура проекта (`GamePackage`)
* `game` — точка входа (`main`), главное окно приложения (`1280x720`), навигация между экранами через `CardLayout` и управление темами.
* `gameMenu` / `gamePanel` / `gameSetting` — главное меню, экран выбора уровней и панель настроек.
* `baseLevel` — абстрактный базовый класс уровня, объединяющий UI-конструктор программы, интерпретатор команд и таймеры анимации.
* `level1`, `level2`, `level3` — уровни игры с уникальной расстановкой препятствий, блоков и целей.
## Запуск проекта
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Скомпилируйте и запустите из терминала:
   ```bash
   javac -d out src/GamePackage/*.java
   java -cp out GamePackage.game
   ```
